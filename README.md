# Audio Converter для Android (Flutter)

Полноценное Android-приложение для конвертации аудио. Построено на Flutter +
ffmpeg_kit — той же технологии ffmpeg, что и в Windows-версии.

## 🎵 Возможности

- **Конвертация в MP3, WAV, M4A/AAC, FLAC**
- Пакетная обработка нескольких файлов
- Выбор битрейта (64–320 kbps + VBR V0)
- Нормализация громкости (EBU R128)
- Сохранение тегов (артист, альбом, год, обложка)
- Пресеты: Музыка / Голос / Подкаст / Архив
- Прогресс по каждому файлу в реальном времени
- Кнопка «Отмена» — мгновенная остановка ffmpeg
- Пропуск уже готовых файлов при повторном запуске
- Современный Material 3 дизайн в оранжевой палитре

## 🚀 Как получить APK — 2 способа

### Способ 1: GitHub Actions (рекомендуемый, БЕЗ установки Android Studio)

GitHub сам соберёт APK в облаке — вам ничего ставить не нужно!

1. **Создайте аккаунт на GitHub** (если ещё нет) — https://github.com/signup
2. **Создайте новый репозиторий**:
   - Зайдите на https://github.com/new
   - Имя: `audio-converter` (или любое)
   - Тип: **Public** (бесплатная сборка Actions)
   - Нажмите **Create repository**
3. **Загрузите файлы** в репозиторий:
   - Можно перетащить всю папку `audio-converter-flutter/` в веб-интерфейс GitHub
   - Или использовать git:
     ```bash
     cd audio-converter-flutter
     git init
     git add .
     git commit -m "Initial commit"
     git branch -M main
     git remote add origin https://github.com/ВАШ_ЛОГИН/audio-converter.git
     git push -u origin main
     ```
4. **Запустите сборку**:
   - В репозитории откройте вкладку **Actions**
   - Слева выберите **Build Android APK**
   - Нажмите **Run workflow** → зеленая кнопка
   - Дождитесь окончания (~10-15 минут)
5. **Скачайте APK**:
   - Откройте завершённый workflow run
   - В самом низу — раздел **Artifacts**
   - Нажмите **AudioConverter-debug-apk** — скачается .zip с APK внутри
6. **Установите на телефон**:
   - Распакуйте ZIP на телефоне или ПК
   - Перекиньте `app-debug.apk` на телефон
   - На телефоне: откройте файловый менеджер → тапните по APK
   - Разрешите установку из неизвестных источников
   - Готово!

### Способ 2: Локальная сборка через Flutter

Если хотите собирать сами и иметь больше контроля:

1. **Установите Flutter** — https://docs.flutter.dev/get-started/install
2. **Установите Android Studio** (для Android SDK) — https://developer.android.com/studio
3. **Откройте терминал** и проверьте:
   ```bash
   flutter doctor
   ```
   Все галочки должны быть зелёными.
4. **Перейдите в папку проекта**:
   ```bash
   cd audio-converter-flutter
   ```
5. **Установите зависимости**:
   ```bash
   flutter pub get
   ```
6. **Соберите APK**:
   ```bash
   flutter build apk --debug
   ```
7. **Готовый APK**:
   ```
   build/app/outputs/flutter-apk/app-debug.apk
   ```

## 🎯 Как пользоваться

1. Откройте приложение **Audio Converter**
2. При первом запуске **разрешите доступ к аудио** (системный диалог)
3. Выберите формат (MP3 по умолчанию)
4. Нажмите **«Выбрать файлы»** или **«Выбрать папку»**
5. Выберите аудио файлы через системный пикер
6. Нажмите оранжевую кнопку **«Конвертировать»**
7. Прогресс виден по каждому файлу
8. Готовые файлы — в `/Android/data/com.example.audio_converter/files/converted/`
9. Можно отменить — кнопка «Отмена» мгновенно остановит ffmpeg

## ⚠️ Ограничения Android

1. **Доступ к файлам** — через системный picker, нельзя напрямую к папкам
2. **Выходная папка** — `/Android/data/com.example.audio_converter/files/converted/`
   - На Android 11+ эта папка недоступна из других приложений
   - Можно использовать Google Files или любой файловый менеджер
3. **Производительность** — конвертация идёт медленнее, чем на ПК
4. **Батарея** — ffmpeg быстро расходует заряд
5. **Размер APK** — ~80-100 МБ (ffmpeg встроен)

## ❓ Частые вопросы

**Q: Почему только 4 формата, а не 11 как на Windows?**
A: ffmpeg-kit для Android поставляется в нескольких вариантах. Для минимального размера
мы используем `min` сборку с основными кодеками. Если нужны все — замените в `pubspec.yaml`
`ffmpeg_kit_flutter_new` на `ffmpeg_kit_flutter_min_gpl` или `https_gpl`.

**Q: Где сохраняются сконвертированные файлы?**
A: В `/Android/data/com.example.audio_converter/files/converted/`. На Android 11+
эта папка доступна только из приложения и системного файлового менеджера.

**Q: Можно ли публиковать в Google Play?**
A: Да, но нужно: release-подпись, иконка, скриншоты, описание, $25 за аккаунт разработчика.
См. https://docs.flutter.dev/deployment/android

**Q: Не собирается на GitHub Actions — ошибка?**
A: Откройте лог workflow, найдите ошибку. Частая проблема — версия Flutter или Java.
Можете прислать текст ошибки — разберёмся.

**Q: Можно сделать и iOS версию?**
A: Да, Flutter кроссплатформенный. Но для сборки iOS нужен macOS + Xcode + Apple Developer
account ($99/год). На GitHub Actions тоже можно — `macos-latest` runner.

## 🐞 Если что-то не работает

1. **Приложение не устанавливается** — проверьте, что разрешена установка из неизвестных источников
2. **Не видит файлы** — дайте разрешение на доступ к аудио при первом запуске
3. **Конвертация падает** — посмотрите `errorMessage` в карточке файла
4. **Не появляется кнопка «Конвертировать»** — добавьте файлы через «Выбрать файлы»
5. **GitHub Actions не запускается** — проверьте, что репозиторий Public, а файлы в корне
